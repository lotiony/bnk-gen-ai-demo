## 주의

- **요건 ID 는 제안서 조견표와 대조 확인이 필요하다**(가이드 §5 DoD). 이 표는
  핸드오프 §2 를 그대로 옮긴 것이고, RFP 기술요건표 원문 제목은 이 저장소에 없다.
- 09 는 **2중 승인이 모두 통과한 상태**(잠금 해제)로 찍혔다. 발표에서 대비를
  강조하려면 잠금 상태도 함께 넣는 편이 낫다 — 시연 화면에서 `↺ 시연 초기화` 후
  다시 캡처하면 된다.
- 12·13 은 관리자 대시보드의 탭이다(GPU·인프라 / 안전·거버넌스). 별도 라우트가 아니다.
- 캡처는 전체 페이지(스크롤 포함)다. 제안서에 넣을 때 상단 영역만 잘라 쓰는 것을 권한다.

## 다시 찍는 법

프리젠터 모드(`P`)를 켜고 `←` `→` 로 순회하면 이 순서 그대로 지나간다.
자동 캡처가 필요하면 `npm run build` 후 `dist/index.html` 을 헤드리스 Chrome 으로
열어 `#/…` 해시로 이동하며 캡처한다(작업 기록은 세션 스크래치패드 참조).
