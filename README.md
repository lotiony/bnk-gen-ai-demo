## ⚠️ 작업 전 반드시 — Claude 모델을 Opus 5 이상으로

**지금까지의 코드는 Claude Opus 5 로 작성했다. 이어받는 사람도 Opus 5 이상을 써 달라.**
Sonnet 계열로 내려가면 결과가 눈에 띄게 갈린다. 큰 작업은 **1M 컨텍스트 변형** 을 권한다.

```
Claude Code 실행 후  /model  로 확인·전환
```

이유는 `docs/BNK_DEMO_CLAUDE_CODE_GUIDE.md` §0-0 에 적어 뒀다. 요지는 세 가지다.

1. Graph RAG 화면은 수십 개의 좌표·타이밍·색이 서로 물려 있어, 좁게 고치면
   반드시 다른 데가 깨진다
2. 참고 원본(`climax/`)은 다크 배경이라 수치를 그대로 옮기면 화이트에서 사라진다
3. **데모에 넣은 기능은 곧 계약 확약이다**(RFP Ⅳ.4.1·Ⅳ.6.7) — 화면과 제안서
   조견표가 어긋나면 그대로 리스크

## 시작하기

```bash
npm install
npm run dev        # 개발 서버
npm run typecheck  # tsc -b --noEmit
npm run build      # dist/index.html 단일 파일 (오프라인 자립형)
```

**완료 판정 전 반드시** ① `npm run build` 성공 ② `dist` 를 네트워크 차단 상태로
열어 전 화면 동작 ③ 1440×900 에서 텍스트 판독 가능.
**개발 서버 확인만으로 "완료" 라고 보고하지 말 것.**

### 프리젠터 모드

발표 중 3막을 끊김 없이 순회하는 장치. **기본은 꺼져 있다**(화살표 키를 가로채지
않도록, 그리고 스크린샷에 찍히지 않도록).

| 키 | 동작 |
|---|---|
| `P` | 프리젠터 모드 켜기/끄기 |
| `←` `→` | 이전 / 다음 화면 (13개 정거장) |
| `1` `2` `3` | 해당 막의 첫 화면으로 점프 |
| `Esc` | 끄기 |

막이 바뀌면 **페르소나가 자동 전환**된다(1막 서사용 → 2막 정오너 → 3막 김플랫 →
화면 14 박거버). 입력창에 타이핑 중일 때는 단축키가 먹지 않는다.
대본은 `src/data/demoScript.ts` 한 곳에서 고친다.

**검증 실측 (2026-08-26)** — `dist/index.html` 을 `file://` 로 열어 헤드리스 Chrome 으로 순회.

| 항목 | 결과 |

| 26개 화면 순회 (1440×900) | 동일 |

| Edge | **미검증** (이 머신에 미설치) — 발표 노트북에서 1회 확인 필요 |

**알려진 이슈**

- `bad`(#D8313D) 와 `brand`(#CB2C10) 가 ΔE 19 로 가깝다. 색 외 채널을 함께 쓸 것(WCAG 1.4.1).
- 화면 9 가 **컬럼 암호화(양방향)+TDE 기반 복호화 접근**을 화면으로 확약한다.
  DB 암복호화 벤더는 아직 미확정이다(핸드오프 §8) — 제안서 조견표와 함께
  확정하거나, 확정 전이면 발표에서 표현 수위를 맞출 것.
- `window.confirm` 8곳이 남아 있다(삭제·재발급 등 파괴적 동작 확인용). 시연 중
  뜨면 브라우저 모달이 화면을 막는다 — 리허설에서 해당 버튼을 피하거나
  인라인 확인 UI 로 바꿀 것.
- 관리자 대시보드 비용 탭의 **호출당 단가 표기**는 상속 자산이다. 미터링 화면
  (11)에서는 단가를 헤드라인으로 쓰지 않았다 — 가격은 별도 트랙이고 화면에
  적힌 수치는 확약으로 읽히기 때문. 발표 전 두 화면의 표현 수위를 맞출 것.

## 절대 규칙 (요약 — 전문은 `CLAUDE.md`)

- 실제 BNK 고객 데이터·실제 내규 문서 **사용 금지**. mock 은 전부 가상 창작물
- BNK 로고 이미지 도용 금지 — 텍스트 워드마크로만
- `localStorage`/`sessionStorage`/`IndexedDB` 금지. 상태는 메모리 스토어만
- mock 은 `src/mock/`·`src/data/` 에 중앙화. 컴포넌트 하드코딩 금지
- 핸드오프 §2 의 14화면 범위를 벗어나는 기능을 임의로 추가하지 않는다
